# PrysUil brand

## Logo

The mark is the "bag owl": an owl whose body is a shopping bag. The bag handle is its crest, the bag corners are its ear tufts, and the orange beak is the only accent.

| File | Use |
| --- | --- |
| `svg/prysuil-lockup.svg` | Owl + wordmark, on light backgrounds |
| `svg/prysuil-lockup-on-dark.svg` | Owl + wordmark, on brown |
| `svg/prysuil-mark.svg` | Owl only, on light backgrounds |
| `svg/prysuil-mark-on-dark.svg` | Owl only, on brown |
| `svg/prysuil-wordmark.svg` | "prysuil" only (Outfit SemiBold, outlined) |
| `svg/prysuil-app-icon.svg` | Rounded app icon (green tile) |
| `svg/prysuil-app-icon-maskable.svg` | Full-bleed icon for Android maskable icons |
| `pwa/*` | Ready-to-use PWA and favicon files |

The wordmark is always lowercase "prysuil" and two-tone: "prys" in green, "uil" in brown (cream on dark backgrounds). Logos are exempt from text-contrast rules, but keep the wordmark at least 24 px tall so the green stays legible. The app's display name in text is "PrysUil".

## Colours

| Name | Hex | Role |
| --- | --- | --- |
| Cream | `#FBFAEE` | Page background; text on brown |
| Brown | `#473C33` | All text and icons |
| Green | `#ABC270` | Headers, app icon, "below target" status |
| Yellow | `#FEC868` | Primary buttons (Add product, Save) |
| Orange | `#FDA769` | Price-drop badges and highlights |

Contrast rules:

- Text is always brown (or cream on brown). Brown passes WCAG AA on cream, green, yellow and orange.
- Never put white or cream text on green, yellow or orange; it fails contrast.
- Never use green, yellow or orange as text colour on cream (the wordmark is the one exception).

## Type

- Headings and wordmark: Outfit, weight 600.
- Body: Outfit 400 (or the system font stack as a fallback).
